# Pomodoro-Focus-Timer
A Python Tkinter desktop timer implementing Pomodoro work sessions, short breaks, and long breaks.

Pomodoro Focus Timer 🍅
A desktop productivity application built with Python and Tkinter, implementing the Pomodoro technique to help users structure their work sessions and breaks.

\Features
25-minute focused work sessions.
5-minute short breaks.
20-minute long breaks after a work cycle.
Countdown timer with a graphical interface.
Start and Reset controls.
Visual session completion indicators.

\Tech Stack
Python
Tkinter
Python after() scheduling
GUI event handling

\Getting Started
Prerequisites
Python 3.x

Tkinter is included with most standard Python installations.

\Run the application
git clone https://github.com/sonu2955/pomodoro-focus-timer.git
cd pomodoro-focus-timer
python main.py
